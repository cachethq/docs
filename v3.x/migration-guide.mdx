---
title: 'Migration Guide'
description: 'Learn how to migrate from Cachet v2.x to v3.x.'
---

<Note>
    The upgrade process from Cachet v2.4 to v3.x is still in development.
</Note>

Our goal is to make the upgrade from v2.4 to v3.x as simple as possible. We will provide detailed instructions on how
to upgrade from v2.4 to v3.x once the upgrade process is finalized. For now, you’ll need to install Cachet v3.x from
scratch or be comfortable with a manual upgrade process.

An important change in Cachet 3.x is that it now relies more on Laravel's own features and best practises. This means
that some configuration options have been removed or changed. We will provide a detailed list of changes in the upgrade guide.

<Steps>
    <Step title="Backup your data">
        Before you start the upgrade process, make sure to backup your database and files. This will allow you to restore your Cachet instance in case something goes wrong.
    </Step>
    <Step title="Install Cachet v3.x">
        We recommend installing Cachet v3.x into a new directory.

        Follow the [installation guide](/v3.x/installation) to install Cachet v3.x on your server.
    </Step>
    <Step title="Migrate your data">
        Once you have installed Cachet v3.x, you can migrate your data from your v2.x instance to the new v3.x instance.
        Run the following command to migrate your data:

        ```bash
        php artisan migrate
        ```

        <Warning>
            The migration path from 2.4 to 3.x is incomplete. Do not run this command without ensuring you have a working backup.
        </Warning>

        We will provide detailed instructions on how to migrate your data once the upgrade process is finalized.
    </Step>
    <Step title="Update your configuration">
        Cachet v3.x has made some changes to its configuration options. You will need to update your `.env` file with the new configuration options.

        We will provide a detailed list of changes in the upgrade guide.
    </Step>
</Steps>
