---
title: 'Migration guide'
description: 'Current limitations of migrating from Cachet v2.4 to v3.x.'
---

<Warning>
    The migration path from Cachet v2.4 to v3.x is incomplete. This page does not provide a complete upgrade procedure. Do not run migrations against your v2.4 database based on these instructions.
</Warning>

To try Cachet v3.x, follow the [installation guide](/v3.x/installation) in a separate directory with a separate database. A fresh installation does not transfer your v2.4 data.

The `php artisan migrate` command runs database schema migrations on the configured database. It does not import data from a v2.x instance into a separate v3.x installation.

Before attempting any upgrade, back up your database and files. Verify that you can restore your v2.4 instance from those backups. A backup does not make the incomplete migration path safe to use.

Cachet v3.x uses more of Laravel's built-in features. Some configuration options have changed or been removed. A complete list of configuration changes and data migration instructions is not yet available in this guide.
