<Warning>
    Cachet v3.x is in development and not yet released. These instructions are for development use only and may change.
</Warning>

## Prerequisites

Cachet v3.x runs on Laravel 12.41.1+ or 13.x and requires:

- PHP 8.3, 8.4, or 8.5
- [Composer](https://getcomposer.org)
- SQLite, MySQL, MariaDB 10.7+, PostgreSQL, or SQL Server

## Installing Cachet

To migrate from Cachet v2.x, read the [migration guide](/v3.x/migration-guide) first. The migration path is incomplete.

<Tabs>
    <Tab title="Manual setup">
        <Steps>
            <Step title="Clone Cachet">
                Clone the Cachet repository:
                ```bash
                git clone -b 3.x https://github.com/cachethq/cachet.git
                cd cachet
                ```
            </Step>
            <Step title="Install dependencies">
                Install the dependencies:
                ```bash
                composer install --no-dev -o
                ```
            </Step>
            <Step title="Update the core package">
                Update the `cachethq/core` dependency:
                ```bash
                composer update cachethq/core
                ```
                <Note>
                    This is a temporary step until Cachet v3.x is released.
                </Note>
            </Step>
            <Step title="Set storage permissions">
                Give the user running your web server write access to Cachet's `storage` directory. Cachet uses this
                directory for logs, cached files, sessions, and other runtime data.
            </Step>
            <Step title="Create the environment file">
                Copy the `.env.example` file to `.env`:
                ```bash
                cp .env.example .env
                ```
            </Step>
            <Step title="Generate an application key">
                Generate an application key:
                ```bash
                php artisan key:generate
                ```
            </Step>
            <Step title="Configure the database">
                Set the database connection values in `.env` to match your setup:
                ```ini .env
                DB_CONNECTION=mysql
                DB_HOST=127.0.0.1
                DB_PORT=3306
                DB_DATABASE=cachet
                DB_USERNAME=root
                DB_PASSWORD=
                ```
            </Step>
            <Step title="Publish assets">
                Publish Cachet's assets:
                ```bash
                php artisan vendor:publish --tag=cachet
                ```
            </Step>
            <Step title="Run migrations">
                Run the database migrations:
                ```bash
                php artisan migrate
                ```
            </Step>
            <Step title="Create your first user">
                Run this command, then follow the prompts to create the first user:
                ```bash
                php artisan cachet:make:user
                ```
            </Step>
            <Step title="Enable the scheduler">
                Enable the scheduler by adding the following cron entry:
                ```bash /etc/crontab
                * * * * * php /path/to/cachet/artisan schedule:run >> /dev/null 2>&1
                ```

                Cachet uses the scheduler to send subscriber notifications for completed maintenance and long-running incidents.
            </Step>
            <Step title="Run a queue worker">
                Run a queue worker to deliver email notifications:
                ```bash
                php artisan queue:work
                ```

                <Note>
                    Cachet queues all subscriber emails. The default `sync` queue connection delivers them during the request. For production, use a dedicated queue worker. See the [Laravel queue documentation](https://laravel.com/docs/queues) to run workers with a process supervisor.
                </Note>
            </Step>
        </Steps>
    </Tab>
</Tabs>
