Cachet's beacon sends anonymous usage data to the Cachet team. The data helps us understand which features people use.

## Configuration

The beacon is enabled by default. To opt out, set `CACHET_BEACON` to `false` in your environment:

```ini .env
CACHET_BEACON=false
```

<Tip>
    If your server restricts outbound requests, allow requests to `https://cachethq.io` to keep the beacon working.
</Tip>

### Configuring the scheduler

Cachet registers `cachet:beacon` to run daily at `00:00`. To run the scheduler every minute, add this cron entry:

```bash /etc/crontab
* * * * * php /path/to/cachet/artisan schedule:run >> /dev/null 2>&1
```

<Note>
    Replace `/path/to/cachet` with the path to your Cachet installation.
</Note>

## What data does Cachet collect?

The beacon collects the following data:

- An anonymous identifier for your installation
- Your Cachet version
- Whether Cachet runs in a Docker container
- Your database type
- Usage counts, such as the number of incidents, components, and subscribers
