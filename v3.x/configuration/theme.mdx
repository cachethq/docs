To change your status page's banner and colors, open **Settings**, then **Manage Theme** in the Cachet dashboard.

For custom CSS selectors and programmatic content insertion, see [Theme hooks](/v3.x/configuration/theme-hooks).

## Banner image

To replace the banner at the top of your status page, drag an image into **Banner Image** or click the field to select a file.

<Frame caption="Cachet's 'Manage Theme' Dashboard">
    <img className="block dark:hidden" src="/v3.x/images/manage-theme-light.png" alt="Manage Theme" />
    <img className="hidden dark:block" src="/v3.x/images/manage-theme-dark.png" alt="Manage Theme" />
</Frame>

<Tip>
    Use an image with a 16:9 aspect ratio.
</Tip>

Cachet also uses the image as the logo in outgoing emails. Cachet accepts JPEG, PNG, GIF,
and WebP images up to 1 MB by default. You can change the storage disk, maximum upload size, and accepted image types
with the [image upload environment variables](/v3.x/configuration/environment#image-uploads).

Click **Save** to apply your changes.
By default, Cachet stores images in `storage/app/public`. To make the image publicly accessible, run this command from your Cachet directory:

```bash
php artisan storage:link
```

To restore the default banner image, click **X**.

### Common issues

#### Uploading images returns a `401 Unauthorized`

If uploads return this error behind a reverse proxy, add the proxy's trusted IP addresses to Cachet's `.env` file:

```dotenv
# Replace with your reverse proxy IPs
CACHET_TRUSTED_PROXIES="192.168.1.1,192.168.1.2"
```
