The **Settings** section of the Cachet dashboard contains the settings described below.

## Site name

**Site Name** is the name Cachet displays in the title and header of your status page.

## About section

The **About** section describes your organization, services, or status page.

<Tip>
    **About This Site** supports Markdown formatting.
</Tip>

## Timezone

**Timezone** sets the timezone for incidents and scheduled maintenance.
The status page displays timestamps in the visitor's local time.

## Language

**Language** sets the language of your status page. This setting and [Timezone](#timezone) are on
**Settings**, then **Manage Localization**.

Cachet currently ships with the following locales: Deutsch (DE), Deutsch (AT), Deutsch (CH), English, English (UK),
Spanish (ES), 한국어, Nederlands, Filipino, Português (BR), 简体中文, and 繁體中文.

## Incident days

This setting controls how many days of incidents appear on each page. Older incidents appear on separate pages.

## Major outage threshold

**Major Outage Threshold** is the percentage of components that must be down before Cachet displays a **Major Outage** banner.

## Automatically refresh page

**Automatically Refresh Page** controls whether your status page refreshes automatically.
The refresh interval is in seconds.

## API access

Two settings control access to the [Cachet API](/api-reference):

### Enable API

**Enable API** controls whether the API is available. When disabled, every API request returns a `404` response.
The API is enabled by default.

### Require authentication

**Require Authentication** makes read-only API endpoints require an [API key](/v3.x/configuration/api-keys).
By default, most read-only endpoints are public. Write endpoints and subscriber endpoints always require authentication.

## MCP server

Two settings control [Cachet's MCP server](/v3.x/guide/mcp), which lets AI agents manage your status page over the
Model Context Protocol:

### Enable MCP server

**Enable MCP Server** controls whether the MCP server is available. When disabled, every MCP request returns a `404` response.
The MCP server is disabled by default.

### Require authentication

**Require Authentication** makes every MCP connection require an [API key](/v3.x/configuration/api-keys).
When disabled, read-only tools are public. Write tools still require a key with the matching permission.
Authentication is required by default.

## Other settings

These settings control other parts of your status page.

### Support Cachet

**Support Cachet** controls the **Powered by Cachet** link in the footer of your status page.

Leaving the link enabled helps others find Cachet. Thank you for supporting the project.

### Display graphs

**Display Graphs** shows [metric](/v3.x/guide/metrics) graphs, such as uptime and response time, on your status page.
This setting is enabled by default.

### Recent incidents only

**Recent Incidents Only** limits the incident history to a specified number of days. Cachet hides older incidents.

### Show timezone

**Show Timezone** displays your status page's timezone in the footer.

### Only show disrupted days

**Only Show Disrupted Days** hides days without incidents. By default, the status page displays all days.

### Dynamic favicon

**Dynamic Favicon** changes the browser tab icon to match the current system status.

### Show dashboard link

**Show Dashboard Link** displays a **Dashboard** link in the status page header.
