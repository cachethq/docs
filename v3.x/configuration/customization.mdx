To add custom HTML and CSS to your status page, open **Settings**, then **Manage Customization** in the Cachet dashboard.

## Custom header HTML

Add scripts, styles, or other HTML to this field. Cachet inserts the content into the `<head>` of your status page.
For example, you can add an analytics script here.

### Fathom Analytics

To add [Fathom Analytics](https://usefathom.com/james), paste this script into the custom header field.
Replace `YOUR_SITE_ID` with your Fathom site ID:

```html
<script src="https://cdn.usefathom.com/script.js" data-site="YOUR_SITE_ID" defer></script>
```

<Note>
    This Fathom link is a referral link. If you sign up using the link, you'll receive $10 credit.
    This helps support the Cachet project.
</Note>

## Custom footer HTML

Add scripts, styles, or other HTML to this field. Cachet inserts the content at the end of the `<body>` of your status page.

## Custom CSS

Add CSS without `<style>` tags. Cachet wraps your CSS in those tags and appends it to its own styles.

### CSS variables

Cachet's [accent colors](/v3.x/configuration/theme#accents) use
[CSS variables](https://developer.mozilla.org/en-US/docs/Web/CSS/Using_CSS_custom_properties).
You can override these variables:

| Variable              | Description                                                       |
|-----------------------|-------------------------------------------------------------------|
| `--accent`            | The main accent color used as the background for primary buttons. |
| `--accent-content`    | An often darker primary hue used for text content.                |
| `--accent-foreground` | The color of text content on top of an accented background.       |
| `--accent-background` | The background color of the status page.                          |

Cachet generates light and dark versions of the accent color. Override both versions when you set custom colors:

```css Custom CSS
/* Light mode */
:root {
    --accent: 4, 193, 71;
    --accent-content: 4, 193, 71;
    --accent-foreground: 255, 255, 255;
    --accent-background: 250, 250, 250;
}

/* Dark mode */
@media(prefers-color-scheme: dark) {
    :root {
        --accent: 4, 193, 71;
        --accent-content: 79, 212, 126;
        --accent-foreground: 1, 58, 21;
        --accent-background: 24, 24, 27;
    }
}
```

<Warning>
    Test your colors in both light and dark mode. Check that text, buttons, and links remain readable against their backgrounds.
</Warning>
