[Filament](https://filamentphp.com), an open source dashboard tool for Laravel, powers the Cachet dashboard.
Open your status page's `/dashboard` URL to manage your Cachet installation, including incidents, components, and subscribers.

## User management

To manage dashboard access, see the [Users](/v3.x/guide/users) guide.

## Markdown

Cachet uses [Markdown](https://www.markdownguide.org) for incident messages and component descriptions. Markdown is a
markup language that uses plain text syntax to format content.

```markdown
# Incident Title

This is my **first incident**. It's _really_ [serious](https://www.youtube.com/shorts/1LOQOKXTDLY).
```
