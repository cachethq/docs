Cachet uses the Laravel PHP framework.
If you're new to Laravel, you can learn more about it on the [Laravel website](https://laravel.com/docs).

<Steps>
    <Step title="Install Laravel Herd">
        Install [Laravel Herd](https://herd.laravel.com), a free local development environment for PHP and Laravel.

        Herd installs PHP, Composer, and npm. You can manage their versions through the Herd UI.
    </Step>

    <Step title="Clone Cachet's core">
        Most Cachet development happens in the [`cachethq/core`](https://github.com/cachethq/core) repository.
        Clone it to your local machine:

        ```bash
        git clone git@github.com:cachethq/core.git cachet-core
        ```

        This command creates a directory named `cachet-core`.
    </Step>

    <Step title="Install dependencies">
        Install the dependencies:

        ```bash
        cd cachet-core
        composer install
        npm install
        ```
    </Step>

    <Step title="Running Cachet">
        Run Cachet using SQLite:

        ```bash
        composer start
        ```

        Open your local Cachet instance at `127.0.0.1:8000`. The terminal shows output for:

        - Vite assets
        - Laravel logs
        - Laravel queue

        To stop the server, press <kbd>Ctrl + C</kbd>.
    </Step>
</Steps>
