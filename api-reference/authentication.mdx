title: 'Authentication'
description: 'API keys, request headers, and authentication requirements.'
---

Most `GET` requests are public by default. If **Require Authentication** is enabled in
[API settings](/v3.x/configuration/cachet#api-access), read requests also require an API key.
Subscriber endpoints always require authentication and the `subscribers.manage` ability for read requests.

Write requests require an API key with the matching resource ability.

## API token

An [API key](/v3.x/configuration/api-keys) is a bearer token sent in the `Authorization` header.
This example creates a component with an authenticated request:

```shell
curl https://v3.cachethq.io/api/components \
	-H "Content-Type: application/json;" \
	-H "Authorization: Bearer YOUR_KEY_HERE" \
	-d '{
		"name": "API",
		"description": "An example description",
		"status": 1
	}'
```
