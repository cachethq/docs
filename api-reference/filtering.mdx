## Filtering

The `filter` parameter limits results to matching resources. This request filters incidents by status:

```http
GET /api/incidents?filter[status]=1
```

<Note>
    Supported filter fields vary by endpoint. Each endpoint reference lists its supported fields.
</Note>

## Including related resources

The `include` parameter embeds related resources in the response. Its value is a comma-separated list of relationships:

```http
GET /api/incidents?include=components,updates
```

<Note>
    Supported relationships vary by endpoint. Each endpoint reference lists its supported relationships.
</Note>

## Filtering by metadata

For resources with metadata, `filter[meta][key]` filters by a metadata value:

```http
GET /api/incidents?filter[meta][region]=us-east-1
```

## Sorting

The `sort` parameter accepts a comma-separated list of field names. Fields sort in ascending order by default:

```http
GET /api/incidents?sort=id
```

A hyphen before a field name selects descending order:

```http
GET /api/incidents?sort=-id
```

<Note>
    Supported sort fields vary by endpoint. Each endpoint reference lists its supported fields.
</Note>
