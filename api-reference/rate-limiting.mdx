---
title: 'Rate limiting'
description: 'Request limits, response headers, and configuration.'
---

The default API rate limit is 300 requests per minute per IP address.

The `X-RateLimit-Limit`, `X-RateLimit-Remaining`, and `X-RateLimit-Reset` response headers report the limit, remaining requests, and reset time.

<Tip>
    The `CACHET_API_RATE_LIMIT` environment variable overrides the default limit.
</Tip>
