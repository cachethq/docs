---
title: 'Component statuses'
description: 'Learn about the different component statuses in Cachet.'
---

Unlike incident statuses, component statuses start at `1`. Specify a status when you create or update a component.

A status can be one of the following:

| Status | Name               | Description                                                                                     |
|--------|--------------------|-------------------------------------------------------------------------------------------------|
| `1`    | Operational        | The component is working.                                                                       |
| `2`    | Performance Issues | The component is experiencing some slowness.                                                    |
| `3`    | Partial Outage     | The component may not be working for everyone, for example, in a particular region. |
| `4`    | Major Outage       | The component is not working for anybody.                                                       |
