## Overview

Follow these steps to upgrade a Cachet installation managed with Git.

## Maintenance mode

Put your status page into maintenance mode to display a "Maintenance Mode" message during the upgrade.

Run this command from your Cachet installation's root directory, which contains the `artisan` file:

```bash
php artisan down
```

## Fetch latest code

Fetch the code and check out the release tag. Replace `LATEST_TAG` with the tag for the v2 release you want to install:

```bash
git fetch origin
git tag -l
git checkout LATEST_TAG
```

## Upgrading dependencies

Install the release's dependencies from your Cachet installation's root directory:

```bash
composer install --no-dev -o
```

## Update Cachet

Run Cachet's pending updates:

```bash
php artisan app:update
```

## Turn off maintenance mode

Turn off maintenance mode:

```bash
php artisan up
```
