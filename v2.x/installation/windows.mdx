## Overview

Download and check out the latest tagged v2 release. A branch such as `master` may be broken or unstable.

## Download with Git

```shell
cd /var/www
git clone https://github.com/cachethq/Cachet.git
cd Cachet
git tag -l

v0.1.0-alpha
v1.0.0
v1.1.0

git checkout v1.1.0
```

### Configuring a database

Rename Cachet's `.env.example` file to `.env` in every environment. Laravel 5 reads configuration from this file.

Edit `.env` with the values for your installation.

Here is an example `.env` file for Windows with a MySQL database:

```text .env
APP_ENV=production
APP_DEBUG=false
APP_URL=http://localhost
APP_KEY=SomeRandomString

DB_DRIVER=mysql
DB_HOST=localhost
DB_DATABASE=cachet
DB_USERNAME=homestead
DB_PASSWORD=secret
DB_PORT=null

CACHE_DRIVER=file
SESSION_DRIVER=file
QUEUE_DRIVER=database
CACHET_EMOJI=false

MAIL_DRIVER=smtp
MAIL_HOST=mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=null
MAIL_PASSWORD=null
MAIL_ADDRESS=null
MAIL_NAME=null
MAIL_ENCRYPTION=tls

REDIS_HOST=null
REDIS_DATABASE=null
REDIS_PORT=null

GITHUB_TOKEN=null
```

<Tip>
    If you use SQLite, remove the `DB_HOST` key from `.env`. Run `touch ./database/database.sqlite` and give the file the required permissions.
</Tip>

After installation, set `APP_DEBUG` to `false` to prevent other people from seeing your application's debug information.

In Command Prompt, navigate to your Cachet installation and run:

```shell
composer install --no-dev -o
```

After choosing your database driver, run the migrations to create the tables:

```shell
php artisan migrate --force
```

The output lists the migrations applied to your database.

### Security key

Generate the `APP_KEY` that Cachet uses for encryption:

```shell
php artisan key:generate
```

## Installing Cachet

Run the installation command to perform the following tasks:

- Run migrations
- Run seeders (of which there are none)

```shell
php artisan app:install
```

<Warning>
    Never change `APP_KEY` after installation in a production environment. Doing so causes all encrypted and hashed data to be lost.
</Warning>

## Apache vHosts

Create an Apache virtual host and add its hostname to your `HOSTS` file.

Add the following virtual host to `httpd-vhosts.conf`. Adjust the values for your installation:

```text httpd-vhosts.conf
<VirtualHost *:80>
    ServerAdmin **Intentionally Hidden**
    DocumentRoot "C:\Users\Administrator\Desktop\Cachet\public"
    ServerName status.theobearman.com
</VirtualHost>
```

> Enable `mod_rewrite` for Apache.
>
> In `httpd.conf`, uncomment the following line:
>
> `#LoadModule rewrite_module modules/mod_rewrite.so`
