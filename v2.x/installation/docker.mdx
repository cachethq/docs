## Overview

Cachet community members maintain Docker support.

## Getting started with Docker Compose

Use [docker-compose](https://docs.docker.com/compose/) to launch Cachet, NGINX, and PostgreSQL containers.

1. Clone the repository:
   ```shell
   git clone https://github.com/cachethq/Docker.git cachet-docker
   cd cachet-docker
    ```
2. Edit `docker-compose.yml` to set your [environment variables](https://github.com/cachethq/docker/blob/master/conf/.env.docker).
3. To build an image containing a specific [Cachet release](https://github.com/cachethq/cachet/releases), change the [`cachet_ver` ARG in the docker-compose.yml](https://github.com/CachetHQ/Docker/blob/master/docker-compose.yml) file:
   ```yaml
    cachet:
       build:
         context: .
         args:
           - cachet_ver=v2.3.10
   ```
4. Build and run the image:
   ```shell
   docker-compose build
   docker-compose up
    ```
5. Open your Docker host's IP address in a browser to configure Cachet.

## Running Cachet Docker container manually

Run a database container:
```shell
docker run --name postgres -e POSTGRES_USER=postgres -e POSTGRES_PASSWORD=postgres -d postgres:9.5
```

Run Cachet:

```shell
docker run -d --name cachet --link postgres -e DB_DRIVER=pgsql -e DB_HOST=postgres -e DB_DATABASE=postgres -e DB_USERNAME=postgres -e DB_PASSWORD=postgres -d cachethq/docker:latest
```

Open `http://<ipdockerisboundto>:8000/setup` to configure Cachet.

## Enabling SSL

To enable SSL, run Nginx with your certificates on the Docker host, service, or load balancers in front of the container. Alternatively, add your SSL certificates and settings to the supplied Nginx configuration.

## Notes

- `cachethq/docker` runs on port 8000 by default. With docker-compose, it is exposed on host port 80.
- The `master` branch and `cachethq/docker:latest` automated build are development versions of the [Cachet project](https://github.com/CachetHQ/Cachet). Do not use `master` or `latest` in production, as they may change at any time. Specify a stable [Cachet release](https://github.com/cachethq/cachet/releases) at build time, as shown in step 3 above.
