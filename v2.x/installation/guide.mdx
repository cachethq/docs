## Prerequisites

Install the following dependencies:

- PHP 7.1 with `ext-gd`, `ext-simplexml`, `mcrypt`, and `ext-xml` installed.
- [Composer](https://getcomposer.org)
- APC or Redis for caching.
- A database such as MySQL, PostgreSQL, or SQLite.
- Git (optional depending on installation)

### Composer

Install Composer globally using the [Composer installation guide](https://getcomposer.org/download/). Composer manages Cachet's PHP dependencies.

After installing Composer and cloning Cachet as described below, run this command from the Cachet directory to install the dependencies:

```shell
composer install --no-dev -o
```

## Installing Cachet

<Warning>
    The tags below are examples. Run `git checkout` on the latest v2 release tag.
</Warning>

```bash
cd /var/www # Or wherever you chose to install web applications to
git clone https://github.com/cachethq/Cachet.git
cd Cachet
git tag -l

v0.1.0-alpha
v1.0.0
v1.1.0
v2.0.0
v2.1.0

git checkout v2.1.0
```

### Configuring a database

Rename Cachet's `.env.example` file to `.env` in every environment.

Edit `.env` with the values for your installation.

<Tip>
    Enclose values that contain spaces in double quotes.
</Tip>

```ini
APP_ENV=production
APP_DEBUG=false
APP_URL=http://localhost
APP_KEY=SomeRandomString

DB_DRIVER=mysql
DB_HOST=localhost
DB_DATABASE=cachet
DB_USERNAME=homestead
DB_PASSWORD=secret
DB_PORT=null

CACHE_DRIVER=apc
SESSION_DRIVER=apc
QUEUE_DRIVER=sync
CACHET_EMOJI=false

MAIL_DRIVER=smtp
MAIL_HOST=mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=null
MAIL_PASSWORD=null
MAIL_ADDRESS=null
MAIL_NAME="Demo Status Page"
MAIL_ENCRYPTION=tls

REDIS_HOST=null
REDIS_DATABASE=null
REDIS_PORT=null

GITHUB_TOKEN=null
```

<Tip>
    If you use SQLite, remove the `DB_HOST` key from `.env`. Run `touch ./database/database.sqlite` and give the file the required permissions.
</Tip>

### Setting the application key

Before running the next command, make sure you have write permission for `.env`. Generate the `APP_KEY` that Cachet uses for encryption:

```shell
php artisan key:generate
```

### Using the install command

Run the installation command to perform the following tasks:

- Run migrations
- Run seeders (of which there are none)

```shell
php artisan app:install
```

<Warning>
    Never change `APP_KEY` after installation in a production environment. Doing so causes all encrypted and hashed data to be lost.
</Warning>

## Installation difficulties

### 500 - Internal server error

If you see a 500 error when visiting your status page, you may need to run `chmod -R 777 storage` or `rm -rf bootstrap/cache/*`.

You can also try changing the cache directory's permissions with `chmod -R 777 bootstrap/`.
