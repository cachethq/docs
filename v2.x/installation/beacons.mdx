Cachet can periodically send information about your installation to our remote server. This optional feature collects version information and is intended for future system announcements.

<Tip>
    Beacons are only available in Cachet v2.4 and above.
</Tip>

## What's reported?

We report the following information to our server:

- A unique installation ID
- The current version of Cachet
- A support contact email (the first enabled administrator's email address)
- Anonymous statistics (the number of users, incidents, components, and metrics)

## Disabling beacons

To disable beacons, set the following value in your `.env` file:

```ini
CACHET_BEACON=false
```
