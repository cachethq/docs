## Cachet prerequisites

Install the following on your server:

- PHP 7.3 with `ext-gd`, `ext-simplexml`, `mcrypt`, and `ext-xml`.
- [Composer](https://getcomposer.org/), `ext-mbstring`, and `ext-tokenizer`.
- APC or Redis for caching.
- A driver for your database, such as MySQL, PostgreSQL, or SQLite.
- [Git](https://git-scm.com)


## SQLite

Cachet supports SQLite, but we recommend another database for status pages with high traffic.
 
## MySQL timezone info

Update your MySQL database with the correct timezone information so that metrics display correctly. See [MySQL time zone support](https://dev.mysql.com/doc/refman/5.7/en/time-zone-support.html).

## Developer prerequisites

If you contribute to Cachet, you may need extra dependencies for the parts you change.

To compile Cachet's CSS from SCSS, install the following:

- Node.js
- NPM
- Bower
- Gulp
