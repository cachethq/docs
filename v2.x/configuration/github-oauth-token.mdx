## Overview

Cachet's Markdown support can display GitHub emoji when the `CACHET_EMOJI` environment variable is enabled.

Cachet uses GitHub's public API to support emoji codes such as `:smile:` and `:beers:`.

If Cachet reaches GitHub's API rate limit, your status page can become inaccessible.

To avoid this limit, create a GitHub OAuth token and set it in your `.env` file as described below.

## Enabling emoji

Emoji support is disabled by default. To enable it, set the following value in your `.env` file:

```ini
CACHET_EMOJI=true
```

## Generate a GitHub token

1. Create a new [personal access token](https://github.com/settings/tokens/new?description=Cachet&scopes=user). Give the token a name and select the `user` scopes.
2. Click **Generate token**. Copy the token into your `.env` file:
  ```ini
    GITHUB_TOKEN=my-new-token
  ```
3. Cache the updated configuration:
  ```shell
  php artisan config:cache
  ```
