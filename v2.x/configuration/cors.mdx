By default, Cachet allows access from any third-party server. For security, we recommend that you configure CORS to allow access only from your own domains.

To configure [cross-origin resource sharing (CORS)](http://en.wikipedia.org/wiki/Cross-origin_resource_sharing) to allow only specific domains, follow these steps:

1. Log in to your dashboard.
2. Go to the **Settings** panel.
3. Click **Security**.
4. In **Allowed domains**, enter the domains that can access the API as a comma-separated list:
   ```
   https://demo.cachethq.io,https://status.cachethq.io
   ```
