<Warning>
    The Cachet team does not maintain these integrations. Use each integration's repository for support.
</Warning>

## Cachet 2.x

These integrations are compatible with Cachet 2.x.

| Name                                | Link                                                                                                                 | Description                                                                                                     |
|-------------------------------------|----------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------|
| Cachet Monitor | [Cachet Monitor repository](https://github.com/castawaylabs/cachet-monitor) | Monitors URLs and automatically updates incidents |
| Sensu Cachet | [Sensu Cachet repository](https://github.com/bimlendu/sensu-cachethq) | Sensu handler for updating Cachet |
| Hubot Cachet | [Hubot Cachet repository](https://github.com/willdurand/hubot-cachet) | Hubot script to manage incidents and statuses in Cachet |
| Nagios Notification | [Nagios Notification repository](https://github.com/mpellegrin/nagios-eventhandler-cachet) | Nagios event handler that sends notifications to the Cachet API |
| Salt Cachet | [Salt Cachet repository](https://github.com/alkivi-sas/salt-cachet) | Salt module for Cachet |
| Pingometer | [Pingometer website](https://pingometer.com/) | Website uptime monitoring |
| Cachet URL Monitor                  | [Cachet URL Monitor repository](https://github.com/mtakaki/cachet-url-monitor/) | Monitors a URL using HTTP status codes, latency, payload regular expressions, or a combination of these checks |
| Zabbix-Cachet                       | [Zabbix-Cachet repository](https://github.com/qk4l/zabbix-cachet) | Synchronizes your Zabbix IT Services and Cachet |
| [CheckItOn.Us](http://CheckItOn.Us) | [CheckItOn.Us website](https://checkiton.us/) | Server monitoring tool |
| Cachet-Monitor                      | [Cachet-Monitor repository](https://github.com/gaz492/cachet-monitor) | Monitors URLs by checking status codes, including all Cloudflare HTTP codes. See the repository's README for details. |
| Cachet Manager                      | [Cachet Manager repository](https://github.com/successtar/cachet-manager) | Manages component statuses and automatically generates and updates metrics on your status page. |
