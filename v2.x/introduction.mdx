Cachet is an open-source status page system for reporting incidents, component statuses, and scheduled maintenance.

## Key features

### JSON API

Use Cachet's JSON API to update incidents and component statuses without editing your status page manually.

### Scheduled maintenance

Schedule maintenance events ahead of time. After the maintenance time has passed, the incident appears in the timeline.

### Metrics

Set up metrics in the dashboard to track values such as uptime and error rates.
